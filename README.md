codeintel is a uv-managed Python 3.12 code-intelligence platform that reads configured target repositories without modifying them, extracts deterministic fact JSON under `out/<target>/facts/`, and loads those facts into an embedded Kuzu graph for canned or raw Cypher queries. The current W1 implementation provides the structural extractor for files, modules, classes, functions, imports, inheritance, and best-effort intra-codebase calls, plus the contract CLI surface for indexing, querying, target listing, and future refresh/map/MCP workflows.
